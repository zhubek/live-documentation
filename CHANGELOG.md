# Changelog

## 0.1.0 — Public preview

- Published the standalone **Live documentation** application, derived from Fieldwork Model Studio.
- Added MIT licensing, product documentation, setup/deployment guides, and source-linked examples.
- Included canvases, on-demand module relations, notes, and editable connectors.
- Included domain/API, policy, state, frontend, database, Redis, and agent documentation views.
- Included validated JSON editing, a shared API schema, SQLite persistence, revision conflicts, and recovery drafts.
- Included an external coding-agent CLI to pull, validate, and publish documentation.

The preview retains shared-password login. It does not include a hosted service, billing, individual accounts, or an autonomous AI updater.
