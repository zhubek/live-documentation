# Product direction

Live documentation is an early self-hosted product for teams that want architecture, domain behavior, and frontend contracts in one navigable model.

The code is MIT licensed. Commercial use is allowed under the license. Paid hosting, onboarding, integrations, or support can be offered separately; this repository does not announce prices, service levels, or delivery dates.

## Available in the preview

- Interactive architecture canvases, drill-down, notes, and editable relations.
- Domain, API, policy, state, frontend, database, Redis, and agent examples.
- JSON editing with shared type and reference validation.
- Next.js and SQLite in one container, revision-protected saves, and recovery drafts.
- An API and CLI for external coding agents to update documentation.

## Proposed priorities

These are directions to validate, not committed releases.

| Area | Intended outcome |
| --- | --- |
| Documentation review | See and approve a proposed model diff before publishing |
| Source synchronization | Show source revision, freshness, and unresolved drift |
| Team access | Individual accounts, read-only access, and traceable authorship |
| Recovery | Browse saved revisions and restore through a supported UI |
| Project onboarding | Create clean workspaces without demo-specific conventions |
| Commercial operations | Establish backup, support, update, and deployment expectations before paid hosting |

## Not available today

There is no autonomous documentation agent, guaranteed source synchronization, multi-tenant hosted service, SSO/RBAC, billing, live co-editing, or execution of documented LangGraph workflows. The shared-password workspace is for a trusted team.

## Help shape a pilot

Open a [pilot or integration enquiry](https://github.com/zhubek/live-documentation/issues/new?title=Pilot%20or%20integration%20enquiry) with your stack, documentation scope, and the questions your team needs to answer. Keep private code, models, credentials, and commercial details out of public issues.

That discussion can establish fit and scope. An enquiry is not a purchase or promise of availability.
